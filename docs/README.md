# docs/

Project documentation for humans. Read in this order if you're new:

1. [`HANDOFF.md`](HANDOFF.md) — start here: 10-minute orientation, how to run, where to change what, known limits.
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) — data flow, diagram, what each part does.
3. [`SWAPPING_TOOLS.md`](SWAPPING_TOOLS.md) — how to replace the AI, news source, automation platform or database.
4. [`DECISIONS.md`](DECISIONS.md) — why each tool was chosen and its trade-offs.

What belongs here: explanations that span several folders. Folder-specific notes go in that folder's
`README.md`; the Make build guide lives next to the scenario in `automation/make/`.
